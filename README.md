## Installation

### Quick Install (All Components)
```bash
chmod +x scripts/install_complete_system.sh
./scripts/install_complete_system.sh
```

### Custom Install
```bash
./scripts/install_complete_system.sh --components core,tier1
```

### Dry Run (Preview)
```bash
./scripts/install_complete_system.sh --dry-run
```

## Usage

```bash
# Full installation
complete-installer install

# Install specific components
complete-installer install --components merkabah,omega

# Check installation status
complete-installer status

# Verify system
complete-installer verify

# Rollback installation
complete-installer rollback

# View logs
complete-installer logs
```

## Installation Stages

1. **Pre-flight Checks** - Verify environment
2. **Dependency Installation** - Install required packages
3. **Component Download** - Fetch all components
4. **Component Installation** - Install each component
5. **Configuration** - Setup configurations
6. **Integration** - Connect components
7. **Health Check** - Verify functionality
8. **Post-install** - Cleanup and finalize
